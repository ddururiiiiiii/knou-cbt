# 관리자 계정 운영 매뉴얼 — 2026-09-01 정식 운영 전환용

## 개요
- 로그인 방식: 이메일 + 비밀번호 (Spring Security 폼 로그인)
- 권한 구분: `USER` / `ADMIN` 두 종류, DB엔 `ADMIN`으로 저장되고 Security가 `ROLE_` 접두사를 자동으로 붙임
- 이 문서는 "관리자 계정을 어떻게 만들고, 잠기면 어떻게 풀고, 비밀번호는 어떻게 관리하는지"를 다룸

---

## 1. 신규 관리자 계정 생성 절차

- **관리자 계정을 만드는 화면(가입 UI)이 따로 없음** — 코드상 회원가입 컨트롤러 자체가 없어서, DB에 직접 넣는 방식만 가능함
- 절차
  1. 비밀번호를 BCrypt로 해시함 (평문 비밀번호를 절대 그대로 저장하면 안 됨)
     - 온라인 bcrypt 생성기는 사용하지 않는 걸 권장함 (실제 비밀번호가 외부 사이트로 전송되는 구조라 위험함)
     - 로컬에서 아래처럼 간단히 생성 가능함
       ```java
       new org.springframework.security.crypto.bcrypt.BCryptPasswordEncoder().encode("실제비밀번호")
       ```
       (로컬 프로젝트에 임시 테스트 코드 한 줄 추가해서 실행 → 결과 값만 복사 → 코드는 다시 삭제)
  2. 운영 DB에 직접 계정 INSERT함 (예시, 실제 컬럼명은 스키마 기준으로 재확인 필요)
     ```sql
     INSERT INTO users (email, password, role)
     VALUES ('admin@example.com', '$2a$10$....(bcrypt 해시 결과)....', 'ADMIN');
     ```
  3. 생성 후 반드시 실제 로그인 테스트로 확인함
- 주의: `role` 컬럼엔 `ROLE_ADMIN`이 아니라 `ADMIN`만 저장함 (Security가 자동으로 `ROLE_`을 붙여주는 구조라, 여기에 `ROLE_ADMIN`을 넣으면 오히려 인식 안 됨)

---

## 2. 비밀번호 정책 및 변경 절차

- 저장 방식: BCrypt 단방향 해시 (복호화 불가능 — 비밀번호를 "확인"할 방법은 없고 "재설정"만 가능함)
- 비밀번호 변경 화면도 현재 없음 → 변경이 필요하면 위 1번과 같은 방식으로 DB의 `password` 컬럼을 새 해시값으로 직접 UPDATE함
  ```sql
  UPDATE users SET password = '$2a$10$....(새 해시)....' WHERE email = 'admin@example.com';
  ```
- 권장 규칙 (강제되는 정책은 아니고, 운영자 스스로 지킬 기준)
  - 최소 12자 이상, 다른 서비스와 겹치지 않는 비밀번호 사용
  - 배포 전 기본/테스트 계정 비밀번호가 남아있지 않은지 확인

---

## 3. 로그인 잠금 정책 및 해제 절차

- 잠금 기준: **같은 IP**에서 로그인 5회 연속 실패 시 15분 잠금 (`LoginAttemptService`)
  - 계정 단위 잠금이 아니라 **IP 단위 잠금**임 — 같은 IP를 쓰는 다른 사람도 같이 잠길 수 있음
  - 반대로 관리자 본인이 IP를 바꾸면(와이파이/테더링 전환 등) 잠금이 그대로 풀림
- 잠금 데이터는 **서버 메모리에만 저장됨** (DB 저장 아님)
  - 별도의 "잠금 해제" 기능/화면 없음
  - 해제하려면 방법은 둘 중 하나뿐임
    1. 15분 기다리기
    2. 서버(애플리케이션) 재시작 — 재시작하면 메모리가 초기화되면서 모든 잠금이 풀림
- 운영 중 실수로 관리자 본인이 잠긴 경우, 급하면 2번(재시작)을 쓸 수 있다는 걸 미리 알아두면 됨

---

## 4. 권한 관리 참고사항

- 역할은 `USER`, `ADMIN` 두 가지만 존재함 (세분화된 권한 단계 없음)
- `/admin/**` 경로는 `ROLE_ADMIN`만 접근 가능, 그 외 로그인 필요한 페이지는 로그인만 되어 있으면 접근 가능
- 공지사항 등록/수정/삭제처럼 URL이 조회 화면과 겹치는 기능은 URL 레벨이 아니라 `@PreAuthorize` 메서드 단위로 권한 체크함 — 새 관리자 전용 기능 추가할 때 URL 패턴만 믿지 말고 메서드 권한도 같이 확인 필요함

---

## 5. 자동 로그인(Remember-Me)

- 로그인 시 자동 로그인 체크하면 14일간 세션 유지됨
- 관리자 계정도 동일하게 적용됨 — 공용 PC에서 관리자로 로그인할 때는 자동 로그인 체크 안 하는 걸 권장함
