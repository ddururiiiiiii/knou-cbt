# 배포 전 체크리스트 (2026-09-01 정식 운영 전환용)

## 개요
- 대상: 9/1 정식 배포 직전 최종 점검
- 범위: 환경설정 / 인프라·배포 / 데이터베이스 / 보안 / 모니터링·운영
- 사용법: 배포 하루~이틀 전에 위에서부터 순서대로 체크. 하나라도 미확인이면 배포 보류함.

---

## 1. 환경설정 점검

- [ ] `SPRING_DATASOURCE_URL` / `USERNAME` / `PASSWORD` / `DRIVER_CLASS_NAME` Render 환경변수에 정확히 등록되어 있는지 확인함
- [ ] `SUPABASE_URL`, `SUPABASE_KEY` 값이 운영용 프로젝트 키인지 확인함 (개발용 키 아닌지 재확인)
- [ ] `SENTRY_DSN` — 현재 `application-prod.yml`에는 sentry 설정 섹션 자체가 없고 dev/local에만 있음. prod에서도 에러 수집이 실제로 되는지 배포 직후 확인 필요. 안 되면 prod.yml에 sentry 섹션 추가함
- [ ] `LOGGING_LEVEL_ROOT` 기본값 INFO로 되어있는지 확인함 (DEBUG로 켜져 있으면 로그 폭증 위험)
- [ ] `spring.thymeleaf.cache: true` (prod 프로필) 적용 확인함
- [ ] 활성 프로필이 `prod`로 정확히 설정되어 있는지 확인함 (`SPRING_PROFILES_ACTIVE`)

---

## 2. 인프라 / 배포 환경 점검

- [ ] Render 서비스에 최신 커밋이 정상 배포됐는지 확인함
- [ ] Render GitHub App 연결 상태 정상인지 확인함 (끊겨있으면 자동배포 안 됨 — 재연결 절차는 별도 문서 참고)
- [ ] Render 헬스체크 엔드포인트 정상 응답 확인함
- [ ] 커스텀 도메인 연결 및 HTTPS 인증서 정상 적용 확인함
- [ ] 파일 업로드 용량 제한(20MB) 실제 서버·Nginx/Render 프록시 단에서도 막히지 않는지 확인함
- [ ] DB 커넥션 풀 설정(`maximum-pool-size: 5`)이 Supabase Connection Pooler 제한과 충돌 안 하는지 확인함

---

## 3. 데이터베이스 점검

- [ ] Flyway 마이그레이션 V1~V8까지 운영 DB에 순서대로 정상 적용됐는지 확인함
- [ ] `flyway.baseline-on-migrate: true` 설정값 그대로 유지되는지 확인함 (운영 DB에 기존 데이터 있는 상태에서 적용 시 필요)
- [ ] 운영 DB 백업이 최소 1회 이상 완료되어 있는지 확인함 (백업/복구 리허설 문서 참고)
- [ ] 관리자 계정이 운영 DB에 시드되어 있는지, 비밀번호가 기본값 그대로 방치되어 있지 않은지 확인함
- [ ] 테스트/더미 데이터가 운영 DB에 남아있지 않은지 확인함

---

## 4. 보안 점검

- [ ] 관리자 로그인 브루트포스 방지(IP당 5회 실패 시 15분 잠금, `LoginAttemptService`) 실제 동작 확인함
- [ ] CSP(Content Security Policy) 헤더가 운영 도메인 기준으로 정상 적용되는지 확인함
- [ ] 이미지 업로드 MIME 타입/확장자 검증 정상 동작 확인함
- [ ] 공지사항 본문 XSS Sanitize(Jsoup) 정상 동작 확인함
- [ ] 세션 기반 로그인의 자동 로그인 유지기간(14일)이 의도한 값인지 재확인함
- [ ] 관리자/일반 사용자 권한 분리가 실제 배포 환경에서도 정상 동작하는지 확인함 (403 처리 포함)

---

## 5. 모니터링 / 운영 준비

- [ ] Sentry 알림 규칙(어떤 에러 레벨에서 알림 올지) 설정 확인함
- [ ] 점검 모드(`/admin/maintenance`) 실제 토글 동작 확인함 — ROLE_ADMIN 세션과 응시 중이던 시험 최종 제출은 통과되는지 재확인함
- [ ] 점검 모드 배너 및 503 안내 화면 문구/디자인 최종 확인함
- [ ] 전역 예외 처리(404/403/409/500) 각 상황별 응답 화면 정상 노출 확인함
- [ ] 배포 후 롤백 절차(이전 커밋/이미지로 되돌리는 방법)를 미리 숙지해두었는지 확인함
- [ ] 스모크 테스트 체크리스트(별도 문서) 실행 완료 여부 확인함
