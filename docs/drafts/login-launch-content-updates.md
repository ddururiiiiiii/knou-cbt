## 1. FAQ (`faq.html`)

### faq2 — "회원가입을 해야 이용할 수 있나요?" 본문 교체

```
아니요. 로그인 없이도 모든 기능을 그대로 이용하실 수 있어요. 다만 구글·카카오·네이버 계정으로
로그인하시면 내가 푼 시험의 점수와 답안을 마이페이지에서 다시 확인할 수 있습니다.
```

### faq7 — "개인정보는 어떻게 처리되나요?" 본문 교체

```
로그인 없이 이용하시면 개인정보를 별도로 수집하지 않습니다. 다만 구글·카카오·네이버로 로그인하시면
닉네임과 (제공에 동의하신 경우) 이메일 정도를 수집하며, 이 정보와 응시 기록은 마이페이지에서 언제든
확인하거나 탈퇴를 통해 삭제하실 수 있습니다. 자세한 내용은 <a th:href="@{/privacy}">개인정보처리방침</a>을
참고해 주세요.
```

### 신규 faq 항목 — "로그인한 계정은 어떻게 탈퇴하나요?" (faq7 다음에 삽입)

```
마이페이지에서 회원 탈퇴를 직접 진행하실 수 있어요. 탈퇴하시면 닉네임·이메일 등 개인정보는 즉시
삭제되고, 그동안 쌓인 응시 기록은 누가 풀었는지 알 수 없는 형태로 통계 목적에 한해서만 남습니다.
```

## 3. 개인정보처리방침 (`privacy.html`)

- **시행일**: 실제 반영일로 갱신 (예: "개정일: YYYY년 M월 D일")
- **1. 수집 항목**에 추가:
  ```
  - (선택) 소셜 로그인 시 제공받는 정보: 닉네임, 이메일(제공에 동의한 경우), 소셜 계정 식별자
    (로그인 제공자 및 고유 ID), 선택 입력한 학과
  - (로그인 회원에 한함) 응시 기록: 문제 풀이 이력, 점수, 제출 시각
  ```
- **2. 이용 목적**에 추가:
  ```
  - 회원 식별 및 로그인 상태 유지
  - 응시 기록 저장 및 마이페이지(내 학습 이력) 제공
  ```
- **3. 보유 및 이용 기간**에 문단 추가:
  ```
  로그인 회원의 개인정보는 탈퇴 시까지 보관되며, 탈퇴 시 즉시 삭제됩니다. 응시 기록은 통계 집계
  목적으로 개인 식별 정보를 제거한 상태로 계속 보관될 수 있습니다.
  ```
- **4. 제3자 제공**에 문단 추가:
  ```
  구글·카카오·네이버 로그인을 이용하시는 경우, 로그인 과정에서 각 사의 인증 절차를 거치며 이는
  각 사의 개인정보처리방침을 따릅니다.
  ```
- **6번 앞 또는 뒤에 신규 섹션 "회원 탈퇴" 추가**:
  ```
  로그인한 회원은 마이페이지에서 언제든 직접 탈퇴할 수 있으며, 탈퇴 즉시 개인정보가 삭제됩니다.
  ```
