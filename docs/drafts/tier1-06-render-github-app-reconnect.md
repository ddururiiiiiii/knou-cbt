## 3. 재연결 절차

1. GitHub에서 확인함
   - `Settings > Applications > Installed GitHub Apps`에서 Render 앱이 이 레포(`ddururiiiiiii/knou-cbt`)에 대한 접근 권한을 가지고 있는지 확인함
   - 접근 범위가 "Only select repositories"로 되어 있다면 이 레포가 포함되어 있는지 확인함
2. Render에서 확인함
   - 서비스 > Settings > 저장소 연결 상태 확인함
   - 연결이 끊겨 있으면 "Reconnect repository" 또는 유사한 버튼으로 재연결함 (재연결 시 GitHub 인증 화면으로 리다이렉트될 수 있음)
3. 재연결 후 검증함
   - 테스트용 빈 커밋(`git commit --allow-empty -m "test: 자동배포 웹훅 재연결 테스트"`)을 push 해서 Render에서 새 배포가 자동으로 시작되는지 확인함
   - (실제로 2026-07-30에 이 방식으로 검증한 이력 있음)
4. 그래도 안 되면 수동 배포로 우회함
   - Render 대시보드에서 "Manual Deploy" 버튼으로 직접 최신 커밋 배포함 (임시 조치, 자동배포 문제는 별도로 계속 원인 파악 필요)
