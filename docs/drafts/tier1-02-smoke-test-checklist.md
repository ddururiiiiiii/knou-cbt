# 배포 전 스모크 테스트 체크리스트 (2026-09-01 정식 운영 전환용)

## 개요
- 대상: 운영 서버 배포 직후, 실제 도메인에서 진행하는 최소 기능 확인
- 목적: "배포는 됐는데 핵심 기능이 죽어있는" 상황을 배포 직후 5~10분 안에 잡아내는 것
- 사용법: 새 시크릿창(로그인 세션 꼬임 방지)에서 위에서부터 순서대로 클릭하며 확인함

---

## 1. 비회원 사용자 화면

- [ ] 메인 화면 정상 로딩 확인함 (학과별 바로가기, 최근 공지 미리보기 노출)
- [ ] 학과 → 과목 → 구분(출석대체/기말/계절학기) → 년도 계층 검색 정상 동작 확인함
- [ ] 사용여부(use_yn) 꺼진 학과/과목/시험이 목록에서 실제로 숨겨지는지 확인함
- [ ] 공지사항 목록 및 상세 페이지 정상 노출 확인함 (고정 공지 상단 노출 포함)
- [ ] 로그인 안 한 상태에서 시험 풀기 클릭 시 의도한 동작(로그인 유도 등) 확인함

---

## 2. 로그인 및 시험 응시 플로우

- [ ] 일반 계정으로 로그인 정상 동작 확인함
- [ ] 자동 로그인 체크 후 브라우저 재시작해도 세션 유지되는지 확인함
- [ ] 시험 목록에서 "문제 풀기" 클릭 → 문제/보기/타이머/답안지 정상 렌더링 확인함
- [ ] 텍스트 보기 문제, 이미지 보기 문제(2단/1단) 둘 다 정상 노출 확인함
- [ ] 답안 선택 시 문제 영역과 답안지 실시간 동기화 확인함
- [ ] 미응답 문제 있는 상태로 제출 시도 → 경고 노출 확인함
- [ ] 최종 제출 → 점수/소요시간 결과 화면 정상 노출 확인함
- [ ] "답안 확인하기" → 문제별 정답/오답 리뷰 정상 노출 확인함
- [ ] 단일 정답 문제, 복수 정답 문제(예: `2` 또는 `2,3`) 채점 결과가 실제로 맞게 나오는지 확인함

---

## 3. 관리자 화면

- [ ] 관리자 계정 로그인 정상 동작 확인함
- [ ] 학과/과목/시험 목록 조회 및 페이지네이션 정상 동작 확인함
- [ ] 학과·과목·시험 신규 등록 → 목록에 즉시 반영되는지 확인함
- [ ] 하위 데이터 있는 항목(예: 문제 있는 시험) 삭제 시도 → 삭제 방지 동작 확인함
- [ ] 문제 직접 입력 등록 → 미리보기(정답 표시 포함) 정상 동작 확인함
- [ ] 엑셀 양식 다운로드 → 샘플 데이터로 일괄 업로드 → 정상 반영 확인함
- [ ] 엑셀 업로드 시 시험ID 불일치·문제번호 누락 케이스 → 의도한 대로 차단되는지 확인함
- [ ] 공지사항 작성(Toast UI Editor) → 등록 후 사용자 화면에 정상 노출 확인함
- [ ] 미사용 항목만 보기 체크박스(시험 목록) 정상 동작 확인함

---

## 4. 파일 업로드 / 스토리지

- [ ] 문제 보기 이미지 업로드 → 저장 후 사용자 화면에 정상 노출 확인함 (CSP img-src 차단 여부 포함)
- [ ] 공지사항 첨부 이미지 업로드 → 정상 노출 확인함
- [ ] 20MB 초과 파일 업로드 시도 → 의도한 대로 거부되는지 확인함
- [ ] 허용되지 않는 확장자/MIME 타입 업로드 시도 → 거부되는지 확인함

---

## 5. 보안 / 인증

- [ ] 관리자 로그인 5회 연속 실패 → 15분 잠금 실제 동작 확인함
- [ ] 일반 사용자 계정으로 관리자 화면(`/admin/**`) 접근 시도 → 403 처리 확인함
- [ ] 로그아웃 후 뒤로가기로 이전 화면 재접근 시도 → 재인증 요구되는지 확인함
- [ ] 공지사항 본문에 스크립트 태그 입력 시도 → Sanitize 되어 실행 안 되는지 확인함

---

## 6. 점검 모드 / 예외 처리

- [ ] 관리자 화면에서 점검 모드 ON → 일반 사용자는 즉시 점검 안내 화면(503) 노출 확인함
- [ ] 점검 모드 중 관리자 세션은 정상 접근 가능한지 확인함
- [ ] 점검 모드 중 이미 응시 중이던 시험의 최종 제출은 통과되는지 확인함
- [ ] 점검 모드 OFF → 정상 화면 복귀 확인함
- [ ] 존재하지 않는 URL 접근 → 404 화면 정상 노출 확인함
- [ ] 서버 에러 강제 유발(테스트용) → 500 화면 정상 노출 + Sentry에 실제로 리포팅되는지 확인함
