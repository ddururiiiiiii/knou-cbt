## 1. 이게 뭔가

**KNOU-CBT**는 한국방송통신대학교(KNOU) 학생들을 위한 **비공식 전자 기출문제집 서비스**입니다.

- 관리자가 학과 → 과목 → 시험 → 문제 순으로 기출문제를 등록해두면
- 학생은 실제 시험처럼 문제를 풀고, 채점 결과와 정답 리뷰를 바로 확인할 수 있음
- 종이/PDF로 흩어져 있던 기출문제를 웹 기반 CBT(Computer Based Test) 형태로 옮긴 게 핵심 가치

1인 사이드 프로젝트로 시작해 **2026-09-01 정식(유료) 운영 전환**을 목표로 마무리 작업 중인 단계입니다. 지금은 Beta.

## 3. 인프라 현황 (README에는 없는 내용)

### 도메인 · 호스팅
- 도메인: **`knou-cbt.com`** (가비아 구매, `www.knou-cbt.com`이 대표 도메인, 루트는 301 리다이렉트)
- 앱 호스팅: **Render** — 현재 **무료 티어**. 5주차(8/25~8/28)에 Starter($7/월)로 업그레이드 예정
- DB: **Supabase PostgreSQL** — 현재 **무료 티어**. 5주차에 Pro($25/월)로 업그레이드 예정
  - ⚠️ **현재 무료 플랜은 자동 백업이 전혀 없음** ("Free Plan does not include project backups") — Pro 업그레이드 전까지는 운영 DB에 실제 백업이 없는 상태. 리스크를 인지하고 짧은 기간이라 감수하기로 결정함(2026-08-17)
- 배포 방식: GitHub main 브랜치에 push하면 Render가 자동 배포 (GitHub App 연동, 저장소명 변경 시 연결이 끊긴 이력 있음 — 재발 시 참고: `docs/drafts/tier1-06-render-github-app-reconnect.md`)
- CI 파이프라인: 없음 — push하면 검증 없이 바로 배포됨 (참고용 기록, 필요성 판단은 별도)

### 모니터링 · 분석
- **Sentry**: ERROR 레벨 로그 자동 캡처 → 이메일 알림. 무료 티어 사용 중. 관리자 전용 테스트 엔드포인트 `/admin/debug/test-error`로 언제든 재검증 가능(의도적으로 강제 예외 발생)
- **Google Analytics 4**: 측정 ID `G-2J0NPPN1MD`, 도메인을 `knou-cbt.com`으로 등록 완료
- **UptimeRobot 등 별도 가동 모니터링**: 없음 — Render 자체 헬스체크(`/health`)와 Sentry가 사실상 전부

### 수익화
- **Google AdSense**: 기존에 운영자가 개인 티스토리 블로그에 쓰던 계정을 그대로 재사용(새 계정 생성 안 함 — 구글은 동일인의 중복 계정을 실명·결제정보·기기지문 등으로 탐지해서 정지시킬 수 있고, 특히 저작권 같은 "심각한 위반"은 계정 전체가 정지될 수 있어서 신중하게 결정함). `knou-cbt.com`을 사이트로 추가하고 `ads.txt`로 소유권 인증 완료, 심사 결과 대기 중
- 승인되면 해야 할 일: 광고 스크립트를 레이아웃에 삽입 + `SecurityConfig`의 CSP `script-src`에 구글 광고 도메인 추가

### 알려진 리스크 (의사결정 완료, 재론 불필요)
- **기출문제 원문 저작권**: 판례상 시험문제는 창작성 인정 저작물이라 영리 목적 재배포는 원칙적으로 면책 안 됨. 다만 동일 컨셉(방통대 기출 + 애드센스)의 개인 사이트가 오래 문제없이 운영 중인 선례를 확인했고, 실질적 단속 리스크는 낮다고 판단해 운영자가 진행 결정함(2026-08-16)
