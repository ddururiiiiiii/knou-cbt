# 기록용 개발문서 / 기술블로그 소재 목록

> 로컬 CLI 세션의 메모리를 Claude Code 웹 세션과 공유하기 위한 임시 파일입니다.
> 글쓰기 작업이 다 끝나면 이 파일은 삭제해도 됩니다.
> (2026-07-30 최초 정리, 2026-08-07 추가분 포함)

## 📁 기록용 개발문서 (비공개, runbook/체크리스트 스타일)
- 운영 전 익혀야 할 것들 (배포 전 체크리스트)
- 모니터링 도구 구성 (Sentry 설정값, 알림 규칙, 대시보드 링크)
- 개발 로테이션 (Phase 0~4 진행 사이클, 우선순위 정하는 기준)
- 예외 처리 (전역 예외 핸들러 컨벤션, 에러 코드 체계)
- Render 자동배포 웹훅 트러블슈팅 로그
- Flyway + Supabase Connection Pooler 이슈 노트
- DB 마이그레이션 의사결정 로그 (예: V5 시험 category 값 정리 같은 스키마 변경 이유)
- 관리자 계정 운영 매뉴얼 (비밀번호 정책, 계정 잠금 해제 절차)
- Render GitHub App 연결 끊김 원인/재연결 절차
- 배포 전 스모크 테스트 체크리스트
- DB 백업/복구 리허설·롤백 절차 기록
- 개인 프로젝트 월별 운영비 트래킹 (Render/Supabase/도메인)
- 계층적 사용여부(use_yn) 로직 설계 노트 — 학과/과목/시험 3단 use_yn을 AND 조건으로 묶어 노출 제어한 결정 기록
- 스키마-애플리케이션 로직 불일치 체크리스트 — DB는 NOT NULL인데 코드는 이미 nullable을 가정하던 사례
- 가져오기(Import) 기능 검증 원칙 확정본 — "셀 단위 형식은 관대하게, 배치 전체 구조는 엄격하게"
- 로컬 개발환경 구성 가이드 — Docker로 즉석 Postgres 띄우기, 관리자 계정 시드 절차, bcrypt/role 함정
- YAML 설정 트러블슈팅 노트 — 들여쓰기 오류로 `spring.servlet.multipart` 설정이 조용히 무시됐던 사례
- 점검 모드(유지보수) 기능 설계 기록 — DB 플래그+인터셉터로 즉시 토글되는 구조

## ✍️ 기술 블로그 (공개, "문제→시도→해결→교훈" 스토리텔링)
- 관리자 로그인 브루트포스 방지 구현기
- Render + Supabase 조합으로 개인 프로젝트 배포하기
- 로그인 방식 설계기 (세션 vs JWT 등 인증 방식 선택 근거)
- PDF 기출문제 자동 추출 파이프라인 만들기
- 개인 프로젝트에 Sentry 붙이기
- 1인 개발로 방통대 CBT 서비스 만들며 배운 것들 (Phase 0~4 회고)
- 사이드 프로젝트에서 놓치기 쉬운 것들 (개인정보처리방침, SEO 등)
- Render 자동배포가 갑자기 안 됐던 이야기
- Flyway + Supabase 커넥션 풀러 충돌 해결기
- PostgreSQL 한글 정렬 버그 잡은 이야기
- CSP 도입 후 버튼이 안 눌리던 문제 해결기
- N+1 쿼리 최적화기
- 공지사항 미인증 CRUD 취약점 발견/수정기
- PDF 자동화를 포기하고 수기 입력으로 전환한 이유
- 개인 프로젝트 실제 운영비 공개
- 1인 개발자의 유료 오픈 로드맵 관리기
- "아무도 신고하지 않은 버그: 문제 이미지가 저장할 때마다 조용히 사라지던 이야기"
- "미사용으로 껐는데 왜 계속 보이지?" — 계층적 노출 제어 발견/설계기
- "Lombok 게터와 내가 만든 게터가 충돌해서 MyBatis가 헷갈렸던 이야기"
- "이미지는 저장됐는데 화면엔 안 보이는 이유" — CSP img-src + Supabase RLS 이중 원인 디버깅기
- "프레임워크 없이 커스텀 Alert/Confirm/Toast 만들기"
- "가져오기 기능, 어디까지 엄격하게 검증해야 할까" — 엄격→관대→부분적으로 다시 엄격, 왔다갔다한 설계 판단 회고
- (짧은 팁 글) "Spring Security `.roles()`가 이미 `ROLE_` 접두사를 붙여준다"

참고: "예외 처리"와 "개발 로테이션"은 내용에 따라 블로그로도 확장 가능 (예: "왜 이 전역 에러 처리 패턴을 택했나", "1인 개발 우선순위 정하는 법").
